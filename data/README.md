# Données

Les fichiers sources ne sont pas versionnés dans ce dépôt :

- `Contrat.csv` : 30 335 contrats d'assurance habitation (fournis dans le cadre du projet OpenClassrooms).
- `Region.csv` : 38 916 communes, référentiel géographique issu de data.gouv.fr.

Placez-les dans ce dossier pour reproduire l'analyse (séparateur `;`, encodage UTF-8).
